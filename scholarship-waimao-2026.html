A奖学金 · 共 4 类（国家级 / 校级 / 技能竞赛 / 企业专项）

🏅

国家奖学金（GB 顶流）

¥ 10,000 / 年
二年级以上可申请两校区统一评审全国名额翻倍 2024年起
  • 对象：全日制 2 年级及以上特别优秀学生。外贸校区国际商务/物流/商务外语等专业同学均可参评。
  • 硬条件：学习成绩排名 专业前 10% 且无不及格科目；或排名前 30% 但在技能竞赛/创新/道德风尚某方面表现特别突出（需证明）。
  • 参考：全国职业院校技能大赛一等奖 / 互联网+ 省级金奖 / 发表论文或专利，均可破格申报。
  • 注意：同一学年不能同时拿国家奖学金 & 国家励志奖学金，但可叠加国家助学金。
⌛ 一般 9-10 月由辅导员组织申报 → 二级学院公示 → 学校奖助评审委员会 → 校长办公会审定。
🎗

国家励志奖学金

¥ 6,000 / 年
贫困+品学兼优家庭经济困难认定必备不可与国奖同年兼得
  • 对象：二年级以上，已被认定为家庭经济困难学生且成绩优秀。
  • 与国助区别：励志是"奖励"，国助是"资助"——两者可叠加领取。
  • 典型覆盖：全国高职覆盖比例约 3.3%，外贸校区评审与商务校区按两校区分组下达名额。
  • 申请路径：9 月 → 班级评议小组 → 辅导员推荐 → 二级学院公示 5 个工作日。
💡 大一先把家庭经济困难认定做好（开学后 9-10 月），大二起才有资格参评励志奖学金。
🎓

校级奖学金（新生大二起可冲）

¥1000 / 800 / 600
一等奖 3%二等奖 5%三等奖 7%前 15% 入围
  • 金额：一等奖 1000 元 / 二等奖 800 元 / 三等奖 600 元（湘商职院发〔2025〕43 号）。
  • 门槛：上一学年综合素质测评 ≥ 80 分，专业学分平均成绩前 15%，且无挂科。
  • 排名方法：同分情况下，按学分权重较高的课程平均分再排序。
  • 外贸校区同学：由所在二级学院（国际商务 / 国际物流 / 商务外语 / 旅游管理…）单独分组名额。
📝 参评对象：全日制在校生（二年级、三年级）。26 级同学 2027 年 9 月开始有资格评（看大一整学年成绩）。
🥇

技能竞赛奖学金（最高 ¥5000/项）

¥ 5000 封顶
实时发放国家级Ⅰ/Ⅱ类省级Ⅰ/Ⅱ类团队按项目申报
  • 国家级Ⅰ类：一等奖 5000 / 二 3000 / 三 2000 元。
  • 国家级Ⅱ类：一 2000 / 二 1200 / 三 800 元。
  • 省级Ⅰ类：一 2000 / 二 1200 / 三 800 元。
  • 省级Ⅱ类：一 800 / 二 480 / 三 320 元。
  • 团队奖：参赛团队成员自行分配，以项目为单位申报，牵头部门核定后由学工部实时发放。
🏆 外贸校区强项：报关/跨境电商/物流/茶艺/旅游/外语技能赛，近年都有同学拿国奖 5000 档。

企业 / 校友专项奖学金（例：康联奖 3000）

¥ 3000 / 年 例
康联奖学金与国奖/其他企业奖互斥每年 9-12 月评审
  • 康联奖学金：3000 元 / 人 / 年，覆盖会计 3 / 经贸茶 2 / 电商 1 / 旅管 2 / 信息 2（名额参考往年）。
  • 条件：二年级以上，两学期综测 ≥ 80，无处分；两学期均获得过校级奖学金，优先三好学生。
  • 同一学年若已获国家奖学金或其他全校性企业奖学金，不重复参评康联。
📌 外贸校区专项企业奖学金名单以当年学工部通知为准，9 月辅导员会把通知下到各班群。

荣誉称号 · 三好学生 / 优秀学生干部等

称号 + 奖励
三好生 5%优干 10%国家奖学金 = 三好学生标兵
  • 三好学生：综测 ≥ 85 分，班级前 15% 或二等校级奖学金及以上获得者。
  • 优秀学生干部：当年在班团、学生会、社团担任干部且考核合格，学习合格。
  • 文明班级：年级班级总数 10%，奖励 500 元 / 班（到课率 95%+、学费缴清、处分 ≤ 3 人次）。

🎯 荣誉称号会写入毕业档案，对专升本/入党/就业推荐比金额更有长期价值。

国家助学金（一年两学期发放）

¥ 2600 / 3300 / 4800
一等 4800二等 3300三等 2600大一入学即可申报
  • 对象：家庭经济困难全日制专科在校生。
  • 学校分档：一等 4800 / 二等 3300 / 三等 2600（参考 2025-2026 春季公示分档标准）。
  • 2025-2026 春两校区名额参考：一等 2611 / 二等 514 / 三等 2187，替补 35 人。
  • 大一新生开学后提交《家庭经济困难学生认定申请表》即可进入评审池。
  • 休学/退学/受处分 → 根据春季公示会取消资格，替补同学顶上。
💸 分学期打款（大约每学期一半），一般 11-12 月 / 次年 4-5 月到学生本人银行卡。

退役士兵学生 · 全员享受国家助学金

¥ 3700 / 年（免评）
全日制在校退役士兵 全员覆盖无需家庭困难认定
  • 符合"全日制在校退役士兵"身份的同学，不需要家庭经济困难认定，自动享受国家助学金。
  • 对应学院春季公示中设有"退役士兵助学金"专项栏目，单独评审单独发放。
🎖 服兵役教育资助另算：学费补偿/贷款代偿/学费减免最高 12000 元/年。

按申请核定

🏦

生源地信用助学贷款（最主流）

≤ 12000 元 / 年
在校利息全免（国家承担）期限：学制+15年，最长22年利率：LPR - 30 基点
  • 去户籍所在县 / 市区 教育局学生资助管理中心 申请（暑假办理最方便，录取通知书里有《资助政策简介》和申请表）。
  • 优先覆盖 学费 + 住宿费，超出部分可用于生活费。
  • 同一学年不能同时申请生源地贷款 + 校园地贷款，两者二选一。
  • 外贸校区家庭经济困难同学，建议 8 月在老家先办好生源地贷款，到校后把回执交给辅导员即可抵扣学费。
⚠️ 提前办好回执单，避免 9 月入学后两头跑；贷款直接打到学校学费账户，不会经过第三方。

勤工助学（校内岗位）

≥ 8 元 / 小时
贫困生优先不影响上课图书馆/学工/宿管/行政助理
  • 在校贫困学生均可申报，岗位由学工部按学院需求发布。
  • 报酬不低于 8 元 / 小时，按月结算到卡。
  • 外贸校区推荐岗位：图书馆前台、二级学院学工助理、实训室管理员、快递站学生管理员、迎新志愿者补助岗。
💡 岗位名额有限，开学第一周就去辅导员那里打听，不要等国庆后。

E26 级新生 · 资助申请时间线（建议收藏）

次年 4-5 月　国家助学金春季学期部分到账；技能竞赛奖学金赛后发放；有变故随时申请临时困难补助。

F新生常见问答（FAQ）

❓

Q1：大一能拿奖学金吗？

  • A：国家奖/国家励志/校级奖学金看上一学年成绩，大一同学大二才有资格评。国家助学金、特困助、勤工助学、助学贷款 大一直接可以申请。
❓

Q2：外贸校区和商务校区评奖是分开的吗？

  • A：名额是两个校区合计下达（如国助 2025-2026 春共 5312 名），按二级学院评审；外贸校区的同学归自己所在二级学院分组，不是跟商务校区混评，不用担心"另一个校区人多抢名额"。
❓

Q3：国奖 / 国励能不能同时申？

  • A：不能同年兼得；但国奖或国励其中一个，都可以跟国家助学金一起拿（奖励 + 资助是两条线）。
❓

Q4：怕交材料被骗怎么办？

  • A：所有材料只交给辅导员或学院学工办；学校未与任何贷款中介、第三方助学机构合作，凡是要求"先交手续费""微信发身份证/银行卡"的一律是诈骗。
